# Global Weather Center — V9 (70% opacity)

All NOAA/SPC filled risk polygons now use **70% opacity** (fillOpacity: 0.70) for all available outlooks: categorical, tornado, wind, hail, severe probability, and Days 4–8. The official SPC colours and legends remain the same. State outlines, city labels, zoom and UI are unchanged from V8.

To deploy: Extract this ZIP and upload index.html, app.js, style.css and README.md into your existing GitHub Pages repository root, replacing the old versions. Confirm the footer reads `GWC 70% OPACITY V9 · 03 NOV 2026`.
